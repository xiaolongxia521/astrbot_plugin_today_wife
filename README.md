# astrbot_plugin_today_wife

一个为 AstrBot 框架开发的群聊趣味插件，实现"今日老婆"功能，支持固定配对和随机配对两种模式。

## 功能概述

- **双模式支持**：管理员可配置固定 CP，未配置的用户则参与随机配对
- **分群独立**：各群聊数据相互隔离，互不影响
- **每日重置**：每天凌晨自动清空随机配对关系（固定 CP 保留）
- **活跃用户筛选**：仅当天在群内发言的用户才会进入随机配对池
- **排他性绑定**：一旦配对成功，双方互绑，当日不能再被他人抽取
- **头像展示**：配对成功后显示对方 QQ 头像

## 安装方法

1. 将插件文件夹放入 AstrBot 的 `data/plugins/` 目录
2. 安装依赖：`pip install -r requirements.txt`
3. 重启 AstrBot 或在 WebUI 中重载插件

## 使用指令
/今日老婆


- 如果用户有固定配对配置，优先使用固定配对
- 否则从当天发言的群友中随机抽取一位
- 已配对用户再次使用会显示当前老婆

## 配置说明

配置文件路径：`/AstrBot/data/config/astrbot_plugin_today_wife_config.json`
