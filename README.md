# astrbot_plugin_today_wife

一个为 AstrBot 框架开发的群聊趣味插件，实现"今日老婆"功能，支持固定配对、随机配对、强娶、离婚等多种功能，允许拥有多个群老婆。

## 功能概述

### ✨ 核心功能
- **固定配对（永恒老婆）**：管理员可配置固定 CP 配对，每日保留
- **随机配对**：未配置的用户可参与随机配对
- **强娶功能**：强制绑定指定用户为老婆
- **离婚功能**：解除与指定老婆的关系
- **多老婆管理**：支持拥有多个群老婆
- **分群独立**：各群聊数据相互隔离
- **每日重置**：每天凌晨自动重置数据（固定配对保留）
- **头像展示**：老婆数量 ≤ 2 时显示头像，≥ 3 时不显示

### 🔧 新增优化
- **嵌套式配置**：固定配对配置支持嵌套格式，更美观
- **分群隔离**：完全支持分群独立配置
- **猫娘反馈**：所有反馈结尾带"喵~"，更可爱
- **指令反馈优化**：不同操作有不同的反馈信息

## 安装方法

1. 将插件文件夹放入 AstrBot 的 `data/plugins/` 目录
2. 安装依赖：`pip install -r requirements.txt`
3. 重启 AstrBot 或在 WebUI 中重载插件

## 使用指令

### 1. /今日老婆
- **功能**：只显示老婆关系，不增加老婆数量
- **显示内容**：所有老婆列表
- **特点**：老婆数量 ≤ 2 时显示头像，≥ 3 时不显示

### 2. /随机老婆
- **功能**：随机抽取老婆（增加老婆数量）
- **规则**：优先使用固定配对，否则从活跃用户中随机抽取
- **活跃用户**：配置天数内发言过的用户
- **特点**：老婆数量 ≤ 2 时显示头像，≥ 3 时不显示

### 3. /强娶 <@某个成员> 或 /强娶 <QQ号>
- 强制绑定指定用户为老婆
- 支持多次强娶同一个人
- 不会断开之前的老婆关系

### 4. /离婚 <@某个成员> 或 /离婚 <QQ号>
- 解除与指定老婆的关系

## 配置说明

配置文件路径：`/AstrBot/data/config/astrbot_plugin_today_wife_config.json`

### 🎯 新增配置项（嵌套式）

| 配置项 | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `active_days` | 整数 | 1 | 发言活跃天数（用于随机老婆功能）<br>1:仅今日发言<br>2:今日或昨日发言<br>以此类推 |
| `fixed_pairings` | 对象 | {} | 分群固定配对配置<br>格式：{群号: {用户QQ: 老婆QQ}} |
| `max_random_count` | 整数 | 5 | 每日随机抽取群老婆的次数限制 |
| `max_marry_count` | 整数 | 3 | 每日强娶群老婆的次数限制 |
| `max_divorce_count` | 整数 | 2 | 每日离婚的次数限制 |

### 📋 原有配置项

| 配置项 | 类型 | 默认值 | 说明 |
|-------|------|--------|------|
| `reset_hour` | 整数 | 4 | 每日重置时间（小时） |
| `not_in_group_text` | 文本 | 你绑定的老婆今天不在这个群里哦~ | 老婆不在群时的默认提示 |
| `enable_random_pairing` | 布尔值 | true | 是否启用随机配对 |

### 🔒 固定配对配置格式（嵌套式）

```json
"fixed_pairings": {
  "123456789": {
    "111111111": "222222222",
    "333333333": "444444444"
  },
  "987654321": {
    "555555555": "666666666"
  }
}
```

**说明：**
- 第一层键为群号
- 第二层键为用户QQ
- 值为该用户的永恒老婆QQ
- 支持一个群有多个固定配对

## 功能细节说明

### 📊 次数限制
- 所有次数限制每日重置
- 配置中设置为 0 表示无限制
- 固定配对不计入次数限制

### 🔄 每日重置
- 每天凌晨自动重置数据
- 固定配对会保留
- 随机配对数据会被清除
- 保留配置天数内的发言记录

### 👥 群成员获取
- 使用 AstrBot 的 API 获取群成员信息
- 支持获取群成员列表、成员详情等

## 反馈信息

```

```

### 强娶反馈
```
@用户 强娶成功！现在你的群老婆有：QQ1、QQ2 喵~
```

### 离婚反馈
```
@用户 离婚成功！现在你的群老婆有：QQ1 喵~
```
或
```
@用户 离婚成功！你现在没有群老婆了~ 喵~
```

## 注意事项

1. 此功能仅限群聊使用
2. 老婆数量 ≥ 3 时不显示头像
3. 强娶功能不会破坏已有的老婆关系
4. 所有操作都有详细的日志记录
5. `/随机老婆` 会优先使用固定配对，第一次使用时会绑定固定老婆
